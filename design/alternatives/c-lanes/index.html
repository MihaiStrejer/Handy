02

Two messages per utterance

The session constructs a fresh request each time. Handy keeps no continuing model conversation or server conversation ID in this path. Assembly

SYSTEM · TASK AND CONTRACT

How to interpret the data

Effective profile prompt + named references to user data + strict response contract

Prompt placeholders refer to fields in the data message. Captured text, dictionary and memory remain reference data. Native destination handles stay in Rust.

USER · JSON DATA ENVELOPE

What this utterance supplies

dictionary: canonical words + mishearings short_term_memory: stored correction text input_context: app + capture availability transcript: recognized speech

All four fields are sent even if the prompt omits a placeholder. Missing selection is explicit; only a verified nonempty selection authorizes replace_selection.

↩

The reply has three fields: text, operation, effect. An effect can propose a remembered correction or mishearing. It is kept in the session; no feedback writer applies it to a profile. Parser · Cleanup

Contract summaries, not a captured payload. A synthetic compatibility probe may precede the request. Its process cache stores endpoint compatibility, not prompts or model conversation. Cache

05

The remaining learning decision

P7 · G1 · Open

What counts as successful output before learning?

A successful paste call reports dispatch. This path does not read the destination back to prove the text arrived. Learning needs a completion rule before a proposed effect can update the profile. Current dispatch · Effect lifetime

?

Concrete case: the endpoint proposes remembering “use Codex.” Paste reports success, but the field has not been checked. Should that correction be retained for the next utterance?

G1-A · RECOMMENDED

Read back the result

Learn after a supported field contains the expected output.

Benefit: evidence that output arrived.
Cost: verification work; unsupported targets cannot learn automatically.

G1-B

Ask the user

Let the user confirm the proposed learning action.

Benefit: covers targets without readback.
Cost: confirmation interrupts dictation.

G1-C

Trust dispatch

Learn when the existing paste call succeeds.

Benefit: simple and broad coverage.
Cost: can learn when output never reached the field.

Answer: pending. Recommendation: G1-A. No approval is recorded. Semantic checks, duplicate protection, stale-result handling and feedback persistence still need implementation after this choice.

Decision border colors: orange is open; green is settled; purple is a team decision awaiting customer confirmation.

  54      if transcript.chars().count() > 32_000 {
  55          return Err("Transcript exceeds the profile request limit".into());
  56      }

  59      }

  63          "short_term_memory": context.memory.iter().map(|item| &item.text).collect::<Vec<_>>(),

  66      });

  69          return Err("Context exceeds the profile request limit".into());

  74  fn parse(content: &str, selection: &Captured<String>) -> Result<Prediction, String> {
  75      if content.len() > 128_000 {
  76          return Err("Profile response exceeds its limit".into());
  77      }
  78      let prediction: Prediction = serde_json::from_str(content)
  79          .map_err(|_| "Endpoint returned an invalid profile response")?;
  80      if prediction.text.trim().is_empty() || prediction.text.chars().count() > 32_000 {
  81          return Err("Endpoint returned empty or oversized text".into());
  82      }
  83      let has_selection = matches!(selection, Captured::Present(text) if !text.is_empty());
  84      if (prediction.operation == TextOperation::ReplaceSelection) != has_selection {
  85          return Err("Endpoint operation does not match the captured selection".into());
  86      }
  87      match &prediction.effect {
  88          FeedbackEffect::None {} => {}
  89          FeedbackEffect::AddMisheardForm { keyword_id, phrase }
  90              if !keyword_id.is_empty()
  91                  && keyword_id.chars().count() <= 80
  92                  && !phrase.trim().is_empty()
  93                  && phrase.chars().count() <= 120 => {}
  94          FeedbackEffect::Remember { text }
  95              if !text.trim().is_empty() && text.chars().count() <= 500 => {}
  96          _ => return Err("Endpoint returned an invalid learning action".into()),
  97      }
  98      Ok(prediction)
  99  }
