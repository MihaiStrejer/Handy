Five interruptions, five visible consequences

Cancel

The active session clears; late work cannot attach to a newer recording. [5]

Focus changes

On Windows, the original native window/control must still match at dispatch. [4]

Field or selection changes

For supported native Edit fields, changed selection, text or caret rejects output. [4]

Invalid reply

Malformed or inconsistent replies fail. Raw response text is never the fallback. [3]

Protected field

A protected selection state stops request assembly before sending captured context. [3]

Next utterance: current destination + latest saved profile → new request. There is no ongoing model chat; compatibility caching only remembers an endpoint check.

Capture boundary: selection capture supports native Windows Edit controls. Terminal, browser and VS Code selection is unavailable. Workspace capture remains deferred. [6]

Evidence boundary: these are diagrams of the current code, not a recording. This page does not establish full voice execution or successful insertion into every destination. The field recheck happens before paste; it does not prove completion.
